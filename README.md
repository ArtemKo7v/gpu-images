# gpu-images

Docker images of GPU model servers. Each directory is one image, built by its own
workflow and published as `ghcr.io/artemko7v/gpu-images/<directory>`.

| Image | Contents |
|---|---|
| [higgs-audiocpp](higgs-audiocpp/README.md) | Higgs Audio v3 TTS, audio.cpp, CUDA 12.9 |
| [qwen3-tts-audiocpp](qwen3-tts-audiocpp/README.md) | Qwen3-TTS Base, audio.cpp, CUDA 12.9 |
